# Research

**What this is.** The bookshelf. Every investigation thread's output, filed unchanged and grouped by topic, with its thread and author in the frontmatter. The practice files were distilled from these; the distillation lives in `design/`, `product/`, `references/` and `decisions/`.

**Come here when.** A ruling needs tracing to its evidence, a Frame, Research or UX thread needs a source no distilled file covers, or you want the full argument behind a short rule.

**Start with.** The topic folder, then the file whose description matches. Agents never load this folder on their own; a prompt may attach one file, labelled `[research: <why>]`, and never in a build thread.
