# Research prompts

**What this is.** Prompts for research threads that can be run more than once. Each names its question, its role, its attachments and the moment that makes it worth running. A stub is filled out before its first run.

**Come here when.** A product reaches the moment a prompt names, or the answer an earlier run produced no longer fits: a different product, a changed tool or model, or a decision's revisit trigger.

**Start with.** The table in [`../README.md`](../README.md), which lists every trigger and says when to run a prompt again. Attach [`../shared-context.md`](../shared-context.md) and the named role.
