# Directory map

Every markdown file under `docs/` (224), grouped by folder. Generated by `yarn directory-map` from each file's `description`, which is written as a trigger: it says when to read the file. Do not edit by hand; CI fails when this is out of date. Each folder's own `README.md` carries the same table for that folder. How the layers relate, and what loads when, is in [`docs/index.md`](../index.md).
