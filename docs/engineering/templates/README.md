# Engineering templates

**What this is.** The templates the tooling reads from the repo root: `toolkit.template.json` (where the apps, specs and reviewers are) and `settings.template.json` (what agents may run, the sandbox, the hooks). The repo's own copies are `toolkit.json` and `.claude/settings.json`.

**Come here when.** You are porting the toolkit, or a check names one of these files.

**Start with.** Copy the template to its home, fill it, and run `yarn doctor`.
