# Engineering

**What this is.** The engineering layer: the placement and package-graph contract, the pinned stack, and the templates behind `toolkit.json` and the tracked agent settings. The checks that enforce it live in `tooling/`.

**Come here when.** You are about to put a file somewhere, add a package, or change what the agents may run.

**Start with.** [`codebase-conventions.md`](codebase-conventions.md). Dependencies: [`tech-stack.md`](tech-stack.md). The harness files: [`templates/`](templates/README.md).
