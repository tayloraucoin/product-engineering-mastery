# Runbooks

**What this is.** Step-by-step procedures a person runs, each ending in something checkable. Templates among them are filled per run.

**Come here when.** A product repo starts from this one, a new agent tool or model arrives, a release is going out, a variant needs real users, or an incident reached someone.

**Start with.** [`new-project.md`](new-project.md) for a new product repo, which runs the `remove-*.md` runbooks; [`onboard-agent.md`](onboard-agent.md) for agents; [`release.template.md`](release.template.md) for shipping.
