# Add recipes

**What this is.** An add recipe is the inverse of a [remove recipe](../remove/README.md): it brings one module into a product repo that removed it or never had it. It names the module's entry in `toolkit.json`'s `stack` block, every file, variable, dependency and boundaries name to restore or create, the vendor-side setup, and where the code is copied from (this repo, at a named commit). It ends by deleting `"removed": true` from the entry and running `yarn check-stack` and `yarn verify`.

**Come here when.** A product repo needs a module back, or a module this repo does not ship.

**Start with.** None is written yet. The first is written the first time a product repo adds a module, as `<module>.md` in this folder, from the module's remove recipe read backwards.
