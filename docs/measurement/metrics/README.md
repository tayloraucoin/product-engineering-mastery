# Metrics templates

**What this is.** Events, metric definitions, experiment plans and readouts, as blank templates. Each is filled at one moment in the work and read at another.

**Come here when.** A package's instrumentation section needs an event, a metric's formula changes, a variant is about to go live, or cool-down asks what shipped.

**Start with.** [`events.template.md`](events.template.md), then [`definitions.template.md`](definitions.template.md).

## In this folder

| File | What it is for |
| --- | --- |
| [`definitions.template.md`](definitions.template.md) | Fill when a metric is named in a brief, or when a metric's formula, denominator or window changes; the definition is a public API with a version and a changelog. |
| [`events.template.md`](events.template.md) | Fill before a package's instrumentation section cites an event, or when an event is added, renamed or retired; the names, properties, owners and status of every tracked event. |
| [`experiment.template.md`](experiment.template.md) | Fill before a flag flips for a variant, flagged trial or controlled experiment; the success, kill and stopping rules written before any data exists. |
| [`readout.template.md`](readout.template.md) | Fill in cool-down for what shipped this cycle, and at the close of every variant window; answers two questions in order and stops when nothing moved. |
