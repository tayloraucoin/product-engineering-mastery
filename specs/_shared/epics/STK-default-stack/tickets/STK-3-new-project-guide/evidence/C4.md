# STK-3 C4 — cold-reader record

Criterion: a reader holding only the guide and a one-paragraph briefing can name every step and the check that ends it.

**Method.** Two fresh-context subagents (general-purpose, claude-opus-5-5, Claude Code 2.1.232, 2026-10-03). Each was told to read exactly one file, `docs/runbooks/new-project.md`, to open nothing else and run nothing, and was given one synthetic briefing. Each answered four questions: every step with its action and its closing check; the step-0 inputs taken; every place it could not tell what to do; and whether it could name every step and its check. Their answers are summarised here, not pasted; the builder's own judgment is not the evidence.
