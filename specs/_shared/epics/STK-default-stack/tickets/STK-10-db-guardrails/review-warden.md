**Should-fix — `yarn node <db script>` reaches a migrate without asking.** `tooling/hooks/bash-guard.ts:775-776` requires `program` to be `node|tsx|bun|deno` for the `CHANGE_FILE` path check, and `:767` only harvests `args` as script names for `yarn|turbo|bun`.
