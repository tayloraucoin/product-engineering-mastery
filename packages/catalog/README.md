# packages/catalog — the shelf

`@pem/catalog` holds components worth seeing that are not in the kit: shadcn's blocks, ecosystem items catalogued by the job they add, custom components lifted from earlier products, and alternate tracks. Record [0011](../../docs/decisions/records/0011-component-kit-and-catalog.md) says why; [`docs/design/component-sources.md`](../../docs/design/component-sources.md) holds the verdicts and the copy-in mapping.

**Nothing imports this package.** The boundaries lint rejects any app or package that tries. A product takes an item by copying it into its own code, or asks Plumb to promote it into `@pem/ui`. The workshop shows it: `yarn ui:storybook` globs `src/**/*.stories.tsx` beside the kit's stories.

## Layout

```
manifest.json                 the plan: every kit and catalog entry, with its source, layer, kind, wave, ticket
STATUS.md                     generated by yarn check-catalog --write; never edited
src/<source>/<kind>/<name>/   one folder per item: <name>.tsx and <name>.stories.tsx (and LICENSE for a third party)
```

Kinds are the kit's (`packages/ui/AGENTS.md`). Sources are the keys of `manifest.json`'s `sources`.

## Adding an item

1. **Add its entry** to `manifest.json`: `id`, `name`, `source`, `target: "catalog"`, `path` (`packages/catalog/src/<source>/<kind>/<name>`), `kind`, `layer` (`primitive`, `composed` or `block`), `wave` (or `null`), `ticket`.
2. **Copy it in** at a pinned upstream (a GitHub path at a full commit SHA, or the shadcn registry by per-command approval; CS-08), mapped onto house tokens and `@pem/ui` primitives. The token lint stays on. If it needs more than a mechanical rename, give the entry `linkOnly: { url, reason }` instead of code.
3. **Keep the licence:** a third-party folder carries the upstream `LICENSE`.
4. **Write its story:** title `Catalog/<Kind>/<Name>/<Source label>`; `tags: ["source:<id>", "verdict:<source verdict>", "layer:<layer>"]`; `parameters.provenance = { upstream, licence, adapted }`; one story per state, each passing the axe check in `yarn test`.
5. **Prove:** `yarn check-catalog --write`, then `yarn check-catalog --ticket <id>` and `yarn test`.
